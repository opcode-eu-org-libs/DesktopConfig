WINDOWS COMMANDS
================
<Win><w> - Windows manipulate mode
    <r> - resize mode
        <Up>     - horizontal increment
        <Down>   - horizontal decrement
        <Right>  - vertical increment
        <Left>   - vertical decrement
        with <Shift>     - precision increment/decrement
        <Enter>  - with mouse
    <m> - move mode
        <Up>     - move up
        <Down>   - move down
        <Right>  - move right
        <Left>   - move left
        with <Shift>     - precision move
        <Enter>  - with mouse
    <d> - send to desktop
        <xx> move to desktop xx (xx=1...6)
        <Shift><xx> move and jump to desktop xx (xx=1...6)
        <Enter> - show menu

    <h> - horizontal maximize
    <v> - vertical maximize
    <f> - maximize
    <i> - iconify (minimize)

    <t> - always on top
    <b> - always on bottom
    <l> - layer menu

    <Enter> - window menu

    <Esc> - to mode level up / mode exit
